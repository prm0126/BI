# AIRCollab walkthrough video (Higgsfield AI)

Reference screenshots of https://app.airnd.ai and the storyboard that turns them
into a narrated product walkthrough.

| file | window |
|---|---|
| `screenshots/01_landing.png` | public landing page: hero, mission, Featured Collaborators, *Start Collaborating* |
| `screenshots/02_login.png` | login window (*Please login first*) |
| `screenshots/03_dashboard.png` | user dashboard: greeting, summary stats, active collaboration, sidebar (Saved, Collaboration, Chat, Data Center, Shipment, Quotation, Equipment) |
| `screenshots/04_discover.png` | Discover Collaborators (Best Matching) |
| `screenshots/05_discover_results.png` | Discover Collaborators (Search More): filter by expertise / resources, save with the heart icon |
| `screenshots/06_saved.png` | Saved Collaborators (Saved / Contacted tabs) |
| `screenshots/07_chat.png` | real-time Chat (In Progress / Upcoming / Requests / History) |
| `screenshots/08_data_center.png` | Data Center: secure file sharing, upload, metadata table |
| `screenshots/09_shipment.png` | Shipment AI assistant (logistics example: blood sample slides to the UAE) |
| `screenshots/10_quotation.png` | Quotation AI assistant (pricing, estimates, quotation requests) |
| `storyboard.json` | editable scene list (title, narration, camera motion, screenshot, Ken Burns keyframes) |
| `walkthrough_prompt.md` | the single detailed prompt for the whole video, regenerated by `bi-forecast video prompt` |

## Generate

```bash
pip install -e '.[api,video]'

# 1. Higgsfield AI (image-to-video per scene, then stitched)
export HIGGSFIELD_API_KEY=...      # from https://cloud.higgsfield.ai
export HIGGSFIELD_API_SECRET=...
bi-forecast video generate --provider higgsfield --model dop --out aircollab_walkthrough.mp4

# 2. No credentials: local Ken Burns render straight from the screenshots
bi-forecast video generate --provider local --out aircollab_walkthrough.mp4

# Voice-over: neural Piper voice (one-time download, ~60 MB) or espeak-ng fallback
bi-forecast video voice-download          # or: apt-get install espeak-ng
bi-forecast video generate --tts piper    # --no-voice for a silent render

# Print / edit the storyboard and the long-form prompt
bi-forecast video storyboard --out storyboard.json
bi-forecast video prompt

# Capture fresh screenshots (pages behind login need a Playwright storage state)
playwright install chromium
bi-forecast video screenshot https://app.airnd.ai --out shots/landing.png
```

The Equipment scene has no screenshot yet, so it reuses the dashboard
screenshot and zooms into the matching sidebar item. Drop a screenshot of that
page into `screenshots/` and point the scene's `image` at it in `storyboard.json`.

Every scene's `narration` text is spoken over the video and captioned; a scene
is stretched (Higgsfield clips hold their last frame) until its voice-over ends.
`--speech-rate 1.15` speaks faster, `--piper-voice path.onnx` swaps the voice.

The same flow is exposed by the API: `GET /video/prompt`, `GET /video/storyboard`,
`POST /video/generate`, `GET /video/jobs/{id}`, `GET /video/jobs/{id}/download`.

Higgsfield model aliases: `dop` (higgsfield-ai/dop/standard, default),
`kling` (kling-video/v2.1/pro/image-to-video), `kling-standard`, or any full
model path from the Higgsfield catalogue.
